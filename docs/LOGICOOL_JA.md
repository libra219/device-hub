# Logicool マウスのボタンとプロセス連動

Device HUB でマウスを開き、「ボタン」で G 番号と動作を選びます。割当候補は左クリック、右クリック、中クリック、戻る、進む、無効、左 Alt 保持です。左 Alt は「キーボード」から選べます。物理ボタンを押すと Alt が押され、離すと解除されます。左クリックを移すときは、新しいボタンに左クリックを設定してから元のボタンを変更します。

1. 普段使う割当を作り、設定プロファイルにこのマウスを追加して「今の状態」を記録します。
2. ゲーム用の割当を作り、別のプロファイルに記録します。
3. 「プロセス連動」で対象の実行ファイルを選び、「前面になったら適用」にゲーム用、「前面を外れたら適用」に普段用を選びます。最小化中も前面アプリの監視が続きます。

## 実機で確認した通信

| 接続 | HID++ 宛先 | 本体が報告した名前 | ボタン数 |
| --- | --- | --- | --- |
| PRO Wireless 有線、046D:C088 | FF | G Pro Wireless Gaming Mouse | 8 |
| PRO Wireless LIGHTSPEED、046D:C539 | 01 | G Pro Wireless Gaming Mouse | 8 |
| G309 神里綾華版 LIGHTSPEED、046D:C547 | 01 | G309 LIGHTSPEED | 6 |

どちらも vendor collection FF00:0002 の long report 11 を使用します。機種名は 0005、ホストモードの確認は 8100、ボタン割当は 8110 の各機能をルート機能から引きます。8110 の関数 0 で個数、3 でマップを取得し、4 で更新してから再読します。上記両機種でサイドボタンを変更し、マップの一致と復元を確認しました。切替は揮発性のホストマップを使います。G HUB のキーボード割当・マクロの取り込み、Bluetooth 接続は対象外です。

ログオン起動の切替は PowerShell の `scripts/logicool-startup.ps1 -Executable <device-hub.exeのフルパス>` で行います。同じスクリプトに `-Restore` を指定すると、自動起動登録を元に戻せます。

管理者として起動するゲームで左 Alt を使う場合は、管理者 PowerShell から `scripts/install-logicool-resident.ps1 -Executable <device-hub.exeのフルパス>` を実行します。Program Files に配置したアプリをタスクスケジューラがログオン時に最小化して起動します。取り消しは同じスクリプトの `-Restore` です。
